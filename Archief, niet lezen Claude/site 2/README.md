# isabelbrouwer.nl

Statische website voor Isabel Brouwer.

## Structuur

```
/
├── index.html
├── images/
│   ├── logo.png
│   ├── icon.png
│   ├── img-closeup.jpeg
│   ├── img-hg.jpeg
│   └── img-tree.jpeg
└── README.md
```

## GitHub Pages

1. Push naar GitHub repository
2. Ga naar Settings → Pages
3. Source: Deploy from a branch → main → / (root)
4. Klaar — de site is live op `https://[username].github.io/[repo]`

Of koppel je eigen domein isabelbrouwer.nl via Settings → Pages → Custom domain.

## Afbeeldingen toevoegen

Plaats extra foto's in de `images/` map en verwijs ernaar in de HTML als `images/bestandsnaam.jpg`.
